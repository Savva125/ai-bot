# Архитектура серверной версии

```text
Windows: PySide6 + UI Automation + локальная SQLite
                 | HTTPS
                 v
FastAPI: лицензии, токены, квоты, идемпотентность
          |                         |
     PostgreSQL              llama.cpp на GPU
          ^
          | приватный /admin/*
   Telegram-бот (aiogram)
```

## Клиент

`app.py` запускает серверный режим по умолчанию. `access_ui.py` активирует ключ
без блокировки Qt-потока; `remote_ai.py` обращается к API и отменяет HTTP-ожидание
при остановке. Ключи и токены хранятся через `security.py` в хранилище ОС.
Для неструктурированных окон ScreenInterpreter вызывает /v1/inspect через тот же
провайдер и затем локально проверяет ID, типы полей и кнопку отправки.
`endpoints.py` запрещает удалённый HTTP, пароли в URL и неоднозначные адреса.

`screen_agent.py`, `conversation.py`, `reply_tracking.py` сохраняют проверки
актуальности окна, ручного текста, подтверждения отправки и удаления ответов.
Модель не имеет инструментов управления компьютером. Персонализация локальная.
`--demo` явно включает тестовый провайдер, с которым автоматическая работа
запрещена; `--smoke-test` работает только в этом режиме.

## Сервер

`creator_desk_server.api:create_app` создаёт API, `schemas.py` ограничивает данные.
ASGI middleware ограничивает тело 64 KiB, включая chunked-запросы. Ошибки не
отражают ключи или контекст; внутренние ошибки логируются только по типу.

`licensing.py` блокирует строку лицензии PostgreSQL при изменениях, активации
и резервировании генерации. У лицензии не более одного выполняющегося запроса.
UUID запроса уникален внутри лицензии. Повтор с другим контекстом отклоняется;
завершённый возвращает кэш без нового списания. Ошибочный или неопределённый UUID
заново не исполняется. Клиент не повторяет генерацию после сетевого сбоя.

Квота учитывает успешные и выполняющиеся генерации текущих суток UTC.
Ошибка модели освобождает квоту; reply/wait/handoff и серверное распознавание окна расходуют по одному запросу.
Частота: 20 принятых запросов в минуту на лицензию, включая неудачные.
Глобальная ёмкость GPU ограничивается MODEL_PARALLEL; перегрузка возвращает 429.
Зависшие запросы освобождаются после таймаута с запасом, их UUID не переисполняются.

Входные переписки не записываются в PostgreSQL. Ответ кэшируется до часа;
очистка запускается при старте и раз в минуту. При выключенном API очистка
произойдёт после запуска. Метаданные запросов хранятся 31 день.

`inference.py` вызывает приватный llama.cpp, задаёт системный промпт и JSON-схему,
ограничивает контекст и проверяет ответ. Резервного локального провайдера и Node-моста в исходниках нет.
`bot.py` работает с административным API через отдельный токен. Публичный прокси
не маршрутизирует /admin/*. Изменения лицензий записываются в аудит.

## Развёртывание

Одна API-реплика, один uvicorn worker, один бот. Квоты защищены PostgreSQL;
глобальная ёмкость и ограничитель активации действуют в процессе API.
Для нескольких реплик потребуется общий ограничитель и очередь.

Серверные миграции: `creator_desk_server/migrations`, таблица версий
`server_alembic_version`. Клиентские миграции и пользовательские данные отделены.
Сервер не создаёт схему автоматически при запуске API.

Класс DemoProvider — только маркер отключённой AI для диагностики и smoke test;
генератора шаблонных ответов нет. Модели старых таблиц сохранены для проверки
совместимости ранее созданных SQLite-баз и истории миграций.
